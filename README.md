# Mazumder Infotech Ledger — project pack (v5.0)

Primary target: **desktop app** (installable PWA). Secondary: mobile. Data lives in your own Google Sheet.

## File system
```
index.html            GENERATED by tools/build.js from src/Ledger.html (the hosted PWA page)
sw.js                 service worker: offline shell, update flow (build hash is stamped by tools/build.js)
manifest.json         install metadata, desktop shortcuts
css/styles.css        GENERATED (extracted from src/Ledger.html)
icons/                icon.svg, icon-maskable.svg, favicon.svg  (+ PNG fallbacks for iOS / older Android)
_headers  .nojekyll   Netlify security headers / GitHub Pages switch
src/                  Apps Script project: Code.gs, Ledger.html (THE source of truth), appsscript.json
test/                 CHANGELOG.md + all tests (static, backend, client, e2e, pwa.e2e) + helpers/
tools/                build.js, dist.js, make_icons.py
docs/                 PWA_SETUP.md (start here to go live), AUDIT.md, TEST_CHECKLIST.md
prompts/              one prompt per phase for the next AI sessions
reference/            the ORIGINAL pre-migration Firebase app (behaviour reference only)
```
**Rule:** edit only `src/`. Then `npm run build`. Never hand-edit `index.html`, `css/styles.css`.

## Quick commands
`npm install` (once, for tests) · `npm run build` · `npm run dist` (deployable folder) · `npm run serve` · `npm test` (101 tests)

## Go live as a desktop app
See **docs/PWA_SETUP.md** (Sheet side token + "Anyone" API deployment, hosting, pairing, install, security model).

## How to run a phase (repeat for each)
1. Start a new chat. Upload the latest zip.
2. Paste `00_MASTER_CONTEXT.md`, then the phase prompt (e.g. `phase1_stop_data_loss.md`).
3. The AI returns an updated zip. Unzip it.
4. In Apps Script: open Extensions > Apps Script. Replace `Code.gs`, `Ledger.html`
   (and `appsscript.json` if changed — Project Settings > "Show appsscript.json").
5. Deploy > Manage deployments > pencil icon > Version: **New version** > Deploy.
   (Editing the existing deployment keeps the same URL. "New deployment" gives a new URL.)
6. Run `docs/TEST_CHECKLIST.md`. Only then move to the next phase.
7. Make a copy of the Google Sheet before each phase (File > Make a copy) as a backup.

## Step 0 (before Phase 1)
Deploy the baseline as-is on a COPY of the sheet and run the checklist once,
so you know what already works. Note anything that fails and tell the AI in Phase 1.

## Phase order (do not skip)
1. Stop data loss and exposure
2. Make writes correct
3. Robustness and parity with the old app
4. Performance and daily-use speed
5. PWA (hosted front-end + token-secured API)

## Important facts to remember
- Dates are stored as text `YYYY-MM-DD`; do not change columns/order in the Sheet tabs by hand.
- Never edit IDs in the Sheet.
- Apps Script web apps cannot be real PWAs by themselves (no manifest / service worker) — that is why Phase 5 moves the front-end to a static host.

## Phase 1 one-time setup (after pasting v1.0)
1. Paste `Code.gs`, `Ledger.html`, and `appsscript.json` (Project Settings > Show appsscript.json).
2. Reload the Sheet. Run any menu item once: Google will ask for NEW permissions (Drive, Triggers). Allow them; backups need Drive.
3. Menu > Ledger > **Install nightly backup** (once) and **Backup now** (to confirm it works).
4. Menu > Ledger > **Set allowed emails** (leave empty = only you).
5. Deploy > Manage deployments > pencil > New version. Check: Execute as **Me**, Who has access **Only myself**.
6. Run the Phase 1 section of `docs/TEST_CHECKLIST.md`.
Run tests any time (no Google needed): `npm test` (needs `npm install` once for jsdom).

## Phase 2 one-time setup (after pasting v2.0)
1. Paste `Code.gs` and `Ledger.html` (appsscript.json unchanged). Deploy > Manage deployments > pencil > New version.
2. Reload the Sheet, then Menu > Ledger > **Setup / Repair Data Sheets** ONCE (applies whole-column formats, repairs any auto-converted dates, seeds default categories).
3. Run the Phase 2 section of `docs/TEST_CHECKLIST.md`.

## Phase 3 one-time setup (after pasting v3.0)
1. Paste `Code.gs` and `Ledger.html` (appsscript.json unchanged). Deploy > Manage deployments > pencil > New version.
2. Reload the Sheet, then Menu > Ledger > **Setup / Repair Data Sheets** ONCE (renames the Monthly tab, adds the Archived columns).
3. Run the Phase 3 section of `docs/TEST_CHECKLIST.md` and tell the AI what the footer's "offline storage" line says.
